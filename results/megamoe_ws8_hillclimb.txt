      (params flag deterministic_first_tile, on iff weight_eager_stages>0):
      first ticket := cluster linear id (bidz), NO atomic round trip;
      later tickets := atom.add + num_persistent_clusters.  Coverage /
      uniqueness / per-cluster monotonicity preserved (bidz < num_clusters
      <= any offset ticket).  Static mode already walks from bidz.
  (b) TMA-A warp pre-fills min(weight_eager_stages, num_ab_stage) AB stages
      with the PREDICTED first task's fc1 weight k-tiles at kernel start
      (before its first sched consume).  Prediction = nb=1-per-expert
      decode: expert = bidz // I1, m-block = bidz % I1 (I1 = 24 at DSV4-Pro
      geometry), valid for tickets < E_g0*I1 = 528.  Pure A-side identity
      (phase, expert, m-tile); token-block multiplicity does not matter.
  (c) reconcile protocol at first consume: TMA-A compares actual vs
      predicted, publishes a discard count via SMEM flag + NamedBarrier 12

      TMA-B completes the stages with in-bounds dummy B/SFB loads (pool row
